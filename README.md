# GamePipeline
GamePipeline is a desktop application for game developers that simplifies the process of uploading and managing game builds for platforms like Steam, itch.io, and more.


Planned Features:
SteamCMD integration,
itch.io Butler support,
Automated build uploads,
Branch and depot management,
Version tracking,
Changelog editor,
Unreal Engine packaging support,
Upload history and logs,
Discord webhook notifications,
Multi-platform deployment,
Build compression and validation,
Simple and modern UI
